# Original hardware fixtures

These tiny synthetic models were generated for B20's integration checks and are dedicated to CC0. They represent a board, CPU and RAM as boxes; two pieces deliberately have the same display name to check that selection uses original glTF node indices rather than names.

`hardware.glb` is uncompressed; the other variants use Draco, Meshopt, Basis ETC1S, Basis UASTC and Basis UASTC with Zstandard. Textures use an original 16×16 checker image. These are test fixtures, not automatically created projects in the real group.
